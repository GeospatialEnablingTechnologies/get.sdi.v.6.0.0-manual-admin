# GET SDI Portal Admin

**GET SDI Portal Admin** is the back-office management interface for the **GET SDI Portal** platform. It provides administrators with centralized control over users, workspaces, maps, dashboards, geospatial services, files and API access, all through a unified configuration environment.
 
For the front-facing manual and a general description of the application, please visit the [GET SDI Portal Manual](https://geospatialenablingtechnologies.github.io/get.sdi.v.6.0.0-manual/) page.


## Features Covered

The following features are covered in this document:

- **User management**: create, edit and delete user accounts, assign roles.
- **Workspace management**: define and configure workspaces that scope maps and dashboards to specific users, control workspace-level visibility and sharing
- **Map & dashboard configuration**: build and publish maps and interactive dashboards from the back office.
- **GeoServer management**: add GeoServer connection instances and per-user geoserver access permissions.
- **File management**: upload, organize and serve data files and supporting documents.
- **API access management**: generate and revoke API keys and monitor API usage.
